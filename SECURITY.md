# Security policy

## Supported versions

kubeink has not published a stable release yet. Security fixes are made on the
`main` branch and included in the next release.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this
repository and choose **Report a vulnerability**. Include what you found, how
to reproduce it and the impact you expect.

You will receive an acknowledgement within 7 days. We will keep you informed
while the issue is investigated and fixed, and credit you in the advisory
unless you prefer otherwise.
